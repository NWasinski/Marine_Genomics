# Marine Genomics
#### Metagenome assembly of Black Band Disease (infect coral individuals)

#### Analysis of the black band disease metagenome. Assembled reads from nanopore sequencing of black band disease, classified the assembled contigs into bins using metabat2, and performed some functional analysis on the genomes to see what genes are prominent in the bacterial community of this disease.

#### A subset of data was used from JCU PhD student Julia Hung, provided in MB5370 by Ira Cooke.
